# orz-markdown for course materials — concept map

## Key concepts
### What is Alembic?
- **Automated Alignment Across Your Entire Course**: You maintain one central study guide (your "single source of truth"). Alembic uses built-in AI tools to automatically generate aligned slides, practice questions, and assessment guides from that source. When you update the main guide, Alembic flags every connected document so your entire course stays synchronized.  
- **Version Control Without the Coding**: Software engineers use powerful tracking tools like Git so they never lose work and can collaborate effortlessly, but the tools are notoriously complex. Alembic puts that exact power behind standard buttons like Save, Snapshot (e.g., "Fall 2026"), and Restore. You can experiment freely without fear of destroying your master materials.  
- **Seamless Adaptability & Shared Improvements**: You can take an existing open course module, hit Adapt, and receive an editable copy customized to your course in seconds. If another instructor fixes an error or updates a resource, you can merge that improvement directly into your materials with a single click.  
- **Built-in Compliance & Total Portability**: Alembic automatically runs background checks for accessibility (alt-text, heading structures) and copyright attribution. Furthermore, it exports into self-contained web files that open in any browser—meaning your students get zero-cost, fully accessible materials they can keep and read offline without needing an account.

## Course-level learning objectives
- **Big picture**: describe what Alembic is through exploring the website and quick demo courses 
- **orz-markdown**: explain the Markdown mechanism and symbols through experimenting using the orz-markdown editor
- **orz-family**: transform Markdown notes to editable slides or handouts using the orz family.
